 # NGFW Анализатор-логов.

 Этот проект представляет собой простой NGFW Анализатор логов. Фиксирует аномальную активность(несколько DROP-запросов с одного IP) в БД. В будущем возможно дополнение алгоритма анализа логов с помощью библиотеки Scikit-learn.

## Стек технологий
- **Python 3.14** (ООП, Type Hints)
- **SQLite** (хранение агрегированных данных)
- **Pytest** (написание smoke-тестов)
- **Docker** (контейнеризация приложения)

## Как запустить
1. Убедитесь, что у вас установлен Docker.
```bash
docker --version
docker-compose --version
```
2. Выполните команду:
```bash
docker-compose up --build
```
3. Скрипт автоматически запустит smoke-тесты, проанализирует `mock_logs.json` и создаст файл `anomalies.db`.


## Что реализовано
- Парсинг JSON-логов с использованием объектно-ориентированного подхода.
- Логика выявления аномалий (пороговое значение DROP-запросов).
- Интеграция с реляционной базой данных (SQLite).
- Покрытие базовой логики smoke-тестами.
